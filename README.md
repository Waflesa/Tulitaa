# Pulpería Tulita (MVP)

App Android offline-first (Flutter + SQLite) para registrar inventario y ver
el precio de venta sugerido (costo × 1.20).

## Cómo integrarlo
1. `flutter create pulperia_tulita --platforms=android`
2. Reemplace `pubspec.yaml` y la carpeta `lib/` con las de este paquete.
3. `flutter pub get`
4. `flutter run`
